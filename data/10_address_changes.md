# Policy: Shipping Address Changes (POL-AC-10)

1. An address change can be made freely while an order status is "Pending" (not yet in
   Processing).
2. Once an order is "Processing," an address change can only be attempted by submitting an
   urgent carrier-intercept request; success is not guaranteed and must be communicated to the
   customer as such, not promised.
3. Once an order is "Shipped," a support agent cannot change the delivery address. If the
   customer needs to redirect the package, refer them to the carrier's own redirect service if
   the carrier offers one; otherwise treat the situation using the Shipping Delays policy
   (POL-SD-02) if the package does not arrive.
4. International address changes that would change the destination country are never allowed
   after an order is placed, at any status, due to customs/tax implications — the order must
   be cancelled (per POL-OC-05, if eligible) and re-placed instead.
